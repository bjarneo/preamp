# How it works

preamp is one binary. `preamp daemon` is the audio service, `preamp` is the window, and the other commands are the command line. The bar widget is a QML plugin for the Omarchy shell.

## The audio service

`preamp.service` is a systemd user service that runs `preamp daemon`. It starts at login.

1. The service creates a PipeWire sink with the name `preamp` and makes it the default output.
2. Apps play into the `preamp` sink.
3. The service runs the audio through the equalizer, the effects, the width, the room and the balance.
4. The service plays the result into the output that you selected.

The sink and the output stream run in the same PipeWire cycle, so preamp does not add a cycle of latency.

## Outputs and the default sink

- When you select an output in the Omarchy audio panel, preamp plays into that output and stays the default.
- When you connect headphones that you used before, preamp moves to them, applies their pinned preset and shows a notification.
- The volume in preamp is the volume of the output device.
- On a laptop with an Omarchy speaker tuning, preamp plays into the tuning, so the tuning still applies.
- When the service stops, it gives the default output back to the device that it played into.

## Realtime priority

preamp asks RTKit for realtime priority for its audio thread, as PipeWire does. The audio thread then keeps its deadline when the CPU is busy.

preamp asks RTKit directly, not through the desktop portal. A portal that started before `rtkit` was installed reports a realtime budget of 0. A client that asks through such a portal gets a hard realtime limit of 0, and the kernel stops it as soon as audio plays.

Without `rtkit`, preamp runs at normal priority. See [Troubleshooting](troubleshooting.md#audio-breaks-up-when-the-computer-is-busy).

## Theme and language

The window and the bar widget follow the Omarchy theme, the window rounding of Hyprland, and the language in `~/.config/omarchy/language`. A change applies at once. preamp has the same 50 languages as Omarchy.

## Files

| Path | Content |
|---|---|
| `~/.config/preamp/config.json` | Your settings, presets, pins and rules. Do not edit this file while the service runs, because the service writes it again. |
| `~/.cache/preamp/` | The AutoEq index, kept for one week |
| `$XDG_RUNTIME_DIR/preamp.sock` | The socket of the service. See [Socket protocol](ipc.md). |
| `~/.config/omarchy/plugins/preamp/` | The bar widget, from `preamp shell install` |
| `~/.claude/skills/preamp/SKILL.md` | The agent skill, from `preamp skill install` |
| `/usr/lib/systemd/user/preamp.service` | The service unit |
